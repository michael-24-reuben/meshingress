# Webtoon Downloader Tool Disclaimer

This Meshingress module is a guarded wrapper around the external
`Zehina/Webtoon-Downloader` CLI. It does not vendor the upstream project and it
does not guarantee that the upstream command shape, metadata output, or site
behavior will remain stable.

WEBTOON and similar sites change markup, APIs, rate limits, CDN behavior, and
access rules without notice. Daily Pass, Fast Pass, app-only, paid,
authentication-only, region-locked, DRM-protected, or otherwise inaccessible
chapters are outside this module's supported scope.

Use this tool only for user-directed access to public, authorized content for a
specific series URL. The module must not be used for site-wide crawling,
credential capture, credential replay, bypassing access controls, or evading
anti-bot systems. Users remain responsible for complying with applicable
copyright law and website terms.
