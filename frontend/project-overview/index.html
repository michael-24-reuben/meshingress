MCP runtime framework

A modular Java server for discovering, governing, and dispatching tool modules.

Meshingress is a Spring Boot MCP runtime that turns attached tool modules into JSON-RPC callable functions. It keeps tool authoring, transport handling, policy, caching, and runtime loading in separate surfaces so the server can grow without flattening every integration into one application layer.

Overview

The project surface is split by responsibility.

Transport

MCP endpoints

HTTP JSON-RPC requests land at the MCP controller, while WebSocket traffic uses the same method family through the configured MCP socket path.

Tool model

Annotations and SPI

Tool authors can declare functions with annotations or implement the shared handler API when they need direct control over dispatch behavior.

Runtime

Registry and loader

Tool modules are discovered through Spring auto-configuration, bundled dependencies, and the evolving runtime loader path for packaged modules.

Governance

Scopes, cache, audit

Execution is shaped by explicit scopes, dispatch limits, secret redaction, audit settings, and declarative cache behavior for annotated functions.

Goals

The runtime is being shaped around safe extension, not one-off wiring.

  1. 01

    Keep tool authors out of server internals

    Tool modules depend on shared APIs and annotations, while server-only classes own dispatch, authorization, registration, and transport details.

  2. 02

    Make runtime activation deliberate

    Bundled, staging, experimental, and native registration phases give loaded tools provenance instead of treating every source as equivalent.

  3. 03

    Preserve policy at the server boundary

    Scope declarations, approval settings, audit redaction, and dispatch limits remain authoritative even when clients render previews or confirmations.

  4. 04

    Document decisions where future work can resume

    The architect directory keeps durable plans, context, assessments, and resolutions close to the implementation rather than scattering them across chat history.
