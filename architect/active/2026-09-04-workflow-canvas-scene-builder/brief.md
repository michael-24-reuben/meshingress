# Workflow Canvas Scene Builder

Create an official workflow-studio dashboard that exposes every state declared in `states/enums.json`. A single TypeScript event tracker must turn typed triggers into normalized element state and `data-*` attributes. The scene payload, including nodes, edges, and honeycomb placements, is then parsed once and consumed by canvas inspirations.

The dashboard is a controllable state authoring surface. It does not migrate or replace the production `WorkflowCanvas` yet.
