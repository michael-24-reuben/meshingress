# Brief

Expose Toonverse as its own public MCP tool family before continuing generic Open Ink Library book tools.

The first source surface is `toonverse.fetch`, `toonverse.fetch-full`, `toonverse.fetch-chapter`, `toonverse.fetch-chapters`, and `toonverse.search`. It accepts stable, source-agnostic caller terms such as `name`, while source-specific lookup, filtering, and URL construction remain inside `dev.mrk.toolspace.openinklibrary.source.toonverse`.
