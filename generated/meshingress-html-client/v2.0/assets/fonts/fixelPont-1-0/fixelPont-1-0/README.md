fixelPont is a chaotic pixel font. 
it comes in two styles, *regular* and *rounded*, which align perfectly on top of each other, so that *rounded* can be used as a colourful backdrop to *regular*. 

the design arose out of the need for a fitting typeface for one of the short comics in my masters project. it has a playful vertical rhythm, and a decently sized character set, including ByeByeBinary’s post-binary ligatures for the french language.
